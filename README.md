# GalaForum

**DAİMA GALATASARAY** — premium, forum-first Galatasaray supporter platform.
Classic forum depth + modern mobile UX. Independent fan platform; not an official club channel.

## Stack

- Expo SDK 57 · React Native 0.86 · Expo Router (file-based routing)
- TypeScript (strict)
- Supabase (Postgres + Auth + RLS) — optional at this stage; the app runs on an in-memory demo data source when not configured
- `@expo/vector-icons` (Ionicons), `expo-linear-gradient`

## Getting started

```bash
npm install
cp .env.example .env        # optional: fill in Supabase URL + anon key
npm run web                 # or: npm run ios / npm run android
```

Without `EXPO_PUBLIC_SUPABASE_URL` / `EXPO_PUBLIC_SUPABASE_ANON_KEY` the app runs in **demo mode**
(sample members and discussions, labelled "Demo" in the UI). New topics created in demo mode live only
for the current session.

### Supabase

Apply `supabase/migrations/*.sql` to your project (`supabase db push` or the SQL editor). The migration
creates profiles, categories (seeded with the 11 default categories), topics and posts, with RLS enabled on
every table. **Never** put the service-role key in the client or in `.env` files used by Expo.

## Scripts

| Script | What it does |
| --- | --- |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | Unit tests with Node's built-in test runner (formatting, search, categories, demo repository) |
| `npm run export:web` | Production web export (`expo export --platform web`) |

## Structure

```
app/                 Expo Router routes
  (tabs)/            Gündem (home), Maç, Transfer, Topluluk, Daha
  kategori/[slug]    Category topic list
  konu/[id]          Topic detail
  konu-ac            Create topic
  ara                Search
components/ui        Design-system primitives (AppText, Button, Pill, Skeleton, Empty/Error states…)
components/navigation Custom bottom tab bar
constants/           Design tokens (theme.ts) and the 11 categories
features/            Feature modules (home, forum, sections)
hooks/               useForumQuery (small query cache), useResponsive
lib/                 env, supabase client, formatting, search, validation
services/forum/      ForumRepository interface + demo and Supabase implementations
supabase/migrations  Database schema, RLS policies, seed
assets/images        Lion hero asset (original, generated by scripts/generate-lion.py), icons
docs/                Audit and roadmap
```
